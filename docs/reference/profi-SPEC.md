## Зафиксированные решения сессии 2026-08-31 (отличия/уточнения vault-спеки)

1. Браузер: системный Chrome, профиль `data/chrome-profiles/main`,
   CDP `127.0.0.1:9333`, запуск `scripts/browser/start-chrome.sh` (идемпотентен).
   Воркер только подключается по CDP; Chrome живёт отдельно.
2. Тестирование — субагентами, доступ к браузеру строго последовательный.
3. Владелец авторизовал реальные платные отклики в рамках тестов
   (выход за рамки v1-спеки «отправка вручную» — осознанный шаг в v2/v3).
   Протокол первого отклика — в `RULES.md`.
4. Кастомные первые тексты откликов: в прототипе пишет сам агент (ZCode) по
   карточке заказа; API-модель для автономного воркера — позже (M3).
5. Действия в UI — только CDP Input-события с человеческим рандомом;
   чтение — пассивный перехват сети + selective DOM extraction.

## Архитектура АВТОРЕЖИМА (текущая, аудит 2026-08-31)

```
воркер main.py (nohup, 90–120 с): лента → фильтры → кандидат → детали
диспетчер launchd com.profi.autopilot (StartInterval=120 с,
  ~/Library/LaunchAgents/com.profi.autopilot.plist
  → scripts/autopilot_cron.sh → main.py autopilot):
  кандидаты ready/not_sent/pending → жёсткие гейты (цена > 500 ₽,
  позиция > 20, has_bid) → LLM-триаж+текст (GLM-5.3, JSON-вердикт) →
  стоп воркера → run_respond(send=True) → рестарт воркера →
  logs/autopilot.log
гейты: лимит 3/день + потолок 500 ₽ — везде (run_respond);
  позиция ≤ 20 и has_bid — только автопилот; рабочие часы 8–23;
  autopilot.lock (30 мин) от наложений; никакого автопополнения
ставка: config.RATE (2000 ₽/час) — единый источник, на который
  ссылается RULES.md
```

Нюансы живой эксплуатации: GLM-5.3 думающая — max_tokens=3000, иначе
JSON обрезается (инцидент 10:10); карточка может исчезнуть из ленты —
автопилот помечает skipped и не ретраит; у launchd нет ~/.local/bin в
PATH — скрипт диспетчера экспортирует PATH (инцидент exit 127).
